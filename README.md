## 📦 Project 1: Live Institutional FP&A Terminal
**File:** `project_5.py` | **Status:** [Live Deployment](https://financial-engineering-portfolio-wgu77njtvcadfrsbyvcylw.streamlit.app/)

### Overview
A production-grade Financial Planning & Analysis (FP&A) terminal designed for institutional-grade corporate reviews. This tool focuses on Big Tech unit economics, specifically targeting metrics prioritized by high-growth firms like Amazon.

### Key Features:
*   **Operating Leverage Analysis:** Visualizes scalability by comparing Revenue growth against Operating Income expansion.
*   **FCF per Share Tracking:** Analyzes the "Bezos North Star" metric to evaluate fundamental cash generation efficiency.
*   **Hybrid Data Architecture:** Implemented a resilient data layer that bypasses public API throttling by utilizing audited historical benchmarks for Tier-1 tech equities (AMZN, NVDA, AAPL).
*   **Interactive Stochastic Modeling:** Integrated Monte Carlo simulations to allow users to stress-test Free Cash Flow projections in real-time.

## 🚀 Project 2: Algorithmic Equity Valuation & Risk Engine
**File:** `valuation_engine.py`

### Overview
A dynamic Discounted Cash Flow (DCF) model that integrates **Natural Language Processing (NLP)** to quantify market sentiment from live news headlines, automatically adjusting the Equity Risk Premium (ERP).

### Key Features:
*   **Sentiment-Adjusted WACC:** Dynamically nudges the cost of capital based on real-time "Bearish" or "Bullish" headline scores.
*   **Monte Carlo Simulation:** Executes 1,000+ iterations to establish a 95% confidence interval for intrinsic fair value.
*   **Stochastic Modeling:** Replaces static growth assumptions with random normal distributions to model market volatility.

## 🔍 Project 3: Strategic M&A Target Identification Engine
**Files:** `ma_scout.py`, `ma_scout_report.csv`

### Overview
An automated industry-screening tool built for **Corporate Strategy and Private Equity** teams to identify undervalued acquisition targets within a specific sector.

### Key Features:
*   **Multi-Criteria Decision Analysis (MCDA):** Ranks targets using a weighted algorithm: Valuation (40%), Profitability (40%), and Solvency (20%).
*   **Industry Benchmarking:** Compares EV/EBITDA multiples and ROE across 10+ global peers instantaneously.
*   **Automated Reporting:** Generates a strategic CSV shortlist for further due diligence.

## 📊 Project 4: Macro-Economic Sensitivity & Stress Test Engine
**File:** `macro_engine.py`

### Overview
A predictive analytics tool that quantifies the **Macro-to-Micro transmission** of global economic forces (Interest Rates, USD Strength) onto equity valuations.

### Key Features:
*   **Correlation Matrix:** Uses Pearson Correlation to identify relationships between the 10Y Treasury Yield and stock volatility.
*   **Beta-Regression Stress Test:** Projects the impact of a 100bps interest rate shock on specific equity margins.
*   **Data Visualization:** Utilizes Seaborn Heatmaps to visualize risk clusters across different macro scenarios.
